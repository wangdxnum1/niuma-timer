# v1.1.0 发布实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 CHANGELOG `[未发布]` 区整批功能正式发布为 GitHub Release v1.1.0（CHANGELOG 定稿 + 双语 README 补全 → 一键发布脚本 → 发布后核对）。

**Architecture:** 纯文档与运维流程，零代码改动。内容前置单独一笔提交（防止被 release.bat 的 `git add -A` 混进发布提交），随后 `release.bat 1.1.0 /y` 自动完成版本同步、测试、构建、打包、tag、push、GitHub Release。

**Tech Stack:** bat 脚本（release.bat / common.bat）、Python（scripts/publish_release.py，gh-less 发布路径）、Git（wincred + openssl）、Rust/Tauri 构建。

## Global Constraints

- 版本号固定 **1.1.0**，日期 **2026-09-18**，仓库 **wangdxnum1/niuma-timer**，分支 **main**
- 不修改任何 Rust / JS 代码，不修改 release.bat / build.bat / common.bat / publish_release.py
- 发布说明逐字来自 CHANGELOG `[1.1.0]` 段（publish_release.py 解析格式：`## [1.1.0] - 日期`，已确认支持）
- README 功能条目**追加到现有功能列表末尾**，不重排既有条目、不新建分组标题
- 提交信息风格：conventional 前缀 + 中文描述（如 `docs(release): ...`）
- 发布依赖 Clash 代理 127.0.0.1:7890（push 与 GitHub API 均走它）

### Task 6: 执行发布

**Files:**
- 自动改写: `src-tauri/Cargo.toml`、`src-tauri/tauri.conf.json`（版本号 1.0.0 → 1.1.0）
- 产出: `bin/package/` 下 NSIS exe + 便携 exe + MSI + `RELEASE_NOTES.md` + `SHA256SUMS.txt`

**Interfaces:**
- Consumes: Task 4 的干净工作区、Task 5 的预检结论
- Produces: tag v1.1.0、main 上的 `release: v1.1.0` 提交、GitHub Release（notes 取 `[1.1.0]` 段 + SHA256SUMS.txt + latest 标记）

- [ ] **Step 1: 跑发布脚本（非阻塞，长时间运行）**

```powershell
release.bat 1.1.0 /y
```

用非阻塞方式启动（预计 10 分钟以上：测试 + 构建 + 打包 + push + 发布），用 CheckCommandStatus 轮询直到结束。若轮询丢输出，改用 `powershell -Command "& .\release.bat 1.1.0 /y *>&1 | Tee-Object -FilePath bin\release-1.1.0.log; exit $LASTEXITCODE"` 落日志复查。

- [ ] **Step 2: 检查输出关键节点**

依次确认输出中出现：
1. `syncing version 1.0.0 to 1.1.0` + `Cargo.toml / tauri.conf.json updated`
2. `[0/5] Testing` 且无 `[ERROR] tests failed`
3. `[1/5] Building release exe` 与 `[2/5] Packaging` 完成，`Artifacts in bin\package` 列出 3 个二进制
4. `files about to be committed:` 清单**只含** Cargo.toml / tauri.conf.json / Cargo.lock（若有）
5. `tag v1.1.0 created` → `pushed main and tag v1.1.0` → `release v1.1.0 published`

任一 `[ERROR]` 即停止，按脚本打印的恢复指引处理（代理未开 → 开 Clash 重跑 push 手动命令；tag 冲突 → 核实后按指引 force）。

- [ ] **Step 3: 验证版本落盘**

Run: `Select-String -Path src-tauri\Cargo.toml,src-tauri\tauri.conf.json -Pattern '1\.1\.0'`
