# 设置页重设计（信息架构重组）设计文档

日期：2026-09-20 · 状态：已确认（brainstorm 可视化会话产出）

## 1. 背景与痛点

设置页现状为 6 张卡片单列长页：功能监控 → 守护 → 数据存储 → **基础配置（14 项混杂）** → 加班配置 → 白名单。用户确认四个痛点全中：

1. **分类混乱**：基础配置卡混了算钱、作息、程序行为、显示偏好四类互不相关设置
2. **缺乏层级**：开关、数字、时间、下拉、分段按钮混排，无分组无层次
3. **信息噪音**：四段大 hint 长文，每卡底部一大段解释文字
4. **整页太长**：无导航，改白名单要滚过前面 5 张卡

## 2. 决策记录（用户逐项确认）

| 决策点 | 结论 |
|--------|------|
| 导航结构 | **不加** tab / 锚点 / 手风琴 / 左导航，保持整页单列卡片风格 |
| 分组方案 | 6 张新卡（见 §3），「算钱优先」排序（A 方案） |
| 降噪 | 长 hint 压成一行，正文收进原生 `<details>` 折叠 |
| 久坐阈值范围 | UI 钳制 30–120 放宽为 **1–120**（上次手测被卡住过） |
| 范围 | 仅设置页内部重组；不动其他页面、不动配置字段与后端 |

## 3. 新分组结构（自上而下）

### 卡① 薪资与作息（新，由基础配置拆出）

「怎么算钱」的全部输入：

- 月薪（`monthly_salary`）
- 发薪日（`payday`）
- 当月实际上班天数（`workdays_override`）+ 刷新按钮（`refreshBtn`）+ 工作日信息（`workdaysInfo`）
- 上午上班 / 上午下班 / 下午上班 / 下午下班（`am_start` / `am_end` / `pm_start` / `pm_end`）→ **2×2 网格**，上午一行下午一行

### 卡② 加班（原「加班配置」，内容不变）

- 启用加班追踪、远程会话不计加班、加班起算时间、加班费、饭补开关 + 金额
- 虚线分节：休息日/节假日加班开关 + 3 个子项
- 长说明（费率沿用规则、补班日规则）→ `<details>` 折叠

### 卡③ 守护（原样）

- 久坐提醒 + 连续活跃阈值（`remind_sedentary_minutes`，**min 属性与钳制放宽为 1–120**）
- 下班提醒、全局快捷键
- hint 压一行：快捷键组合照常展示，双通道/冲突说明 → `<details>` 折叠

### 卡④ 数据监控（「功能监控」+「应用使用白名单」合并）

两卡本就是「统计什么数据」：

- 鼠标键盘活动 / 应用使用 / 媒体播放 3 个开关
- 虚线分节：仅统计白名单开关 + 名单编辑器（输入框 + 添加按钮 + 列表）
- 长说明（匹配规则、大小写）→ `<details>` 折叠

### 卡⑤ 外观（新，由基础配置拆出）

- 时长显示格式（`duration_format`）
- 首页副标题文案（`tagline_style`）+ 自定义输入（`tagline_custom`，仅选「自定义」时显示，现有联动逻辑不变）
- 账单风格分段按钮（`billStyleSeg`：小票 / 仪表盘）
- 托盘悬停显示彩色卡片（`tray_hover_card`）

### 卡⑥ 系统与数据（「数据存储」+ 基础配置的开机自启合并）

- 开机自动启动（`launch_on_boot`）
- 虚线分节：历史数据保留（`retention_days`）+ 存储信息（`storageInfo`）+ 立即整理（`cleanupBtn`）
- 长说明（WAL 收缩、图标缓存、保留期才会删数据）→ `<details>` 折叠

## 4. 降噪规范

- 卡内可见 hint ≤ 1 行（约 40 字以内）
- 超长说明统一收进 `<details class="hint-details"><summary>详情</summary>…</details>`——原生元素，零 JS 依赖，符合项目无框架约束
- 受影响五处：休息日加班费率规则、守护快捷键说明、白名单匹配规则、副标题说明、WAL/缓存说明

## 5. 层级规范

- 时间 4 项 → 2×2 网格（新增 `.time-grid` 类）
- 合并卡内部小节用**虚线分隔线**（呼应现有 hint 分隔风格）
- 开关行右对齐（现有 `.switch-row` 不变）、输入左对齐、行高统一

## 6. 行为变更（仅一处）

久坐阈值 UI 钳制 30–120 → 1–120：

- [index.html](../../frontend/index.html) `min="30"` → `min="1"`
- [app.js](../../frontend/app.js) `readCfg()` 中 `Math.max(30, …)` → `Math.max(1, …)`
- 后端对该字段无硬校验，不受影响

其余所有输入/开关/分段按钮的行为、保存时机（失焦/变更即存、离开设置页 flush）一律不变。
