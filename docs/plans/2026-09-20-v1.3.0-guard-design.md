# v1.3.0「牛马守护」设计文档

> 日期：2026-09-20 · 前置：v1.2.0 数据洞察已完成（待定版发布）
> 主题：打工健康与掌控——手动暂停 + 久坐提醒 + 下班提醒 + 全局快捷键

## 一、背景与目标

v1.2.0 把「事后统计」做到了周维度（周账单 / 热力 / 趋势 / 身体账单），但牛马计时器始终缺
「事中干预」：打工人忙起来忘记喝水起身、到点忘记下班、开会想临时停表只能进设置页关三个开关。

v1.3.0 补齐四件套（各功能独立可用，互不依赖）：

| # | 功能 | 一句话 | 交互归宿 |
|---|------|--------|----------|
| A | 手动暂停监控 | 托盘一键「暂停/恢复监控」，主页显示暂停态 | 托盘菜单 + 主页徽章 |
| B | 久坐提醒 | 连续键鼠活跃 N 分钟，弹「起来喝水」 | 应用内横幅 / 系统通知 |
| C | 下班提醒 | 工作日过 `pm_end` 还在工位，弹「到点下班」 | 同上 |
| D | 全局快捷键 | Alt+Shift+N 显隐主窗 · Alt+Shift+P 暂停/恢复 | 系统级，配置可关 |

联动亮点：久坐横幅的「休息 5 分钟」按钮 = 自动暂停监控 5 分钟后自动恢复——A 与 B 的组合拳。

## 二、A · 手动暂停监控

### 语义

- **临时态**：内存 `AtomicBool`，不落盘；重启后恢复监控（与 `monitor_*` 持久开关语义区分：
  后者是「今天要不要监控」，暂停是「这 30 分钟别记我」）
- **暂停范围**：键鼠采集、前台应用结算、媒体采样三条链路全部停写；已有数据不动
- **与锁屏关系**：锁屏（`lock_monitor::AWAY`）自动暂停是另一层，两者叠加取或——任一为真即停

### 状态机（新模块 `src-tauri/src/pause.rs`）

```rust
static MANUAL: AtomicBool = AtomicBool::new(false);      // 托盘/快捷键手动暂停
static REST_UNTIL: Mutex<i64> = Mutex::new(0);           // 久坐「休息 5 分钟」的自动恢复时刻(ms)

pub fn set_manual(on: bool);                              // 托盘切换
pub fn rest_for(ms: i64);                                 // 久坐联动：REST_UNTIL = now + ms
pub fn is_paused() -> bool;                               // MANUAL || now_ms() < REST_UNTIL
pub fn rest_remaining_secs() -> Option<i64>;              // 休息中剩余秒（徽章倒计时用）
```

### 守卫插入点（照抄锁屏范式，三处）

| 链路 | 位置 | 改法 |
|------|------|------|
| 键鼠采集 | `activity.rs:672` WM_INPUT 回调首行 | 守卫链加 `!pause::is_paused()` |
| 前台结算 | `app_usage.rs:568` settle 门控链 | 同上（锁屏守卫旁） |
| 媒体采样 | `audio_usage.rs` tick_loop ENABLED 检查处 | 同上 |

- **暂停瞬间的结算**：切到暂停前先主动 `app_usage::settle()` 结算当前前台窗口（把已挂表
  时长落库），再置位 MANUAL——暂停前的工时不丢、暂停期间不多记。恢复时 settle 的计时起点
  由下次前台切换/结算自然重建（settle 已有 last_fg 时间戳逻辑，置位前结算即切断）
- **媒体**：audio 的 ENABLED 检查每 5s 轮询，暂停期间轮询照跑但跳过写入，恢复自动续上

### 托盘与主页 UI

- 托盘菜单加一项（排在「刷新工作日」上）：文案随状态切换——
  `pause::is_paused()` ? 「恢复监控」: 「暂停监控」；`MenuItem::set_text` 运行时改写。
  点击即 `set_manual(!is_paused())`，`refresh_tray`（每秒拍）顺带维护文案
- 主页徽章：`get_status_cmd` 返回体加 `paused: bool` 与 `rest_secs: Option<i64>`，
  前端 `renderBadge` 顶部分支：
  - 手动暂停 → `badge off`「已暂停 · 钱先冻结」
  - 休息中 → `badge off`「休息中 · X 分钟后恢复」（每秒倒计时，tick 天然刷新）
  - 其余分支不变（休息日/已下班/搬砖中）
- hero 金额：暂停期间 `get_status_cmd` 的金额字段照常返回计算值，但键鼠/应用数据停更，
  金额自然冻结（前台秒不再累计）——无需前端特判，徽章已说明状态

## 三、B · 久坐提醒

### 触发口径（纯函数，可单测）

```rust
// remind.rs
// 连续活跃 = 距上次「归零点」的分钟数；归零点重置条件：
//   1. 键鼠 idle 超过 IDLE_REST_MINUTES(默认 5 分钟，复用 last_input_ms 判定) → 人已离开
//   2. 任意暂停/锁屏期间不计入（暂停结束后从恢复时刻重新起算）
//   3. 用户点过「知道了」→ 从点击时刻重新起算
// 触发：连续活跃 ≥ remind_sedentary_minutes(默认 50) 且 距上次提醒 ≥ 冷却 5 分钟
fn should_remind(now_ms, last_reset_ms, last_input_ms, paused, away, threshold_min, last_remind_ms) -> bool
```

- 调度：挂 scheduler 60s 节拍（分钟级阈值无需 1s 精度），`remind::tick(app)`
- 状态：内存即可（重启清零，重新起算——礼貌）
- **锁屏不算**：away 时 tick 直接 return；解锁后从解锁时刻起算

### 通知通道（双通道，按主窗可见性分流）

| 场景 | 通道 | 内容 |
|------|------|------|
| 主窗可见 | 应用内自绘横幅（新 DOM，复用 toast 的视觉语言但可交互、常驻不自动消失） | 「已连续搬砖 N 分钟，起来喝口水」 + 按钮 [知道了] [休息 5 分钟] |
| 主窗隐藏 | 系统通知（`tauri-plugin-notification`） | 「已连续搬砖 N 分钟，起来喝口水 🐎」纯文案 |

- 横幅交互：
  - **知道了** → 重置连续计时（last_reset_ms = now），横幅关闭
  - **休息 5 分钟** → `pause::rest_for(5*60_000)` + 重置计时 + 横幅关闭；主页徽章切「休息中」
    倒计时，到点 scheduler 自动复位 REST_UNTIL（`is_paused()` 读时刻即可，无需额外线程）
- 系统通知点击行为不做定制（默认激活应用即打开主窗，用户再点横幅交互）

### 配置

| 字段 | 默认 | 说明 |
|------|------|------|
| `remind_sedentary_enabled` | `true` | 久坐提醒开关 |
| `remind_sedentary_minutes` | `50` | 连续活跃阈值（30–120，设置页 number 输入） |

## 四、C · 下班提醒

### 触发口径（纯函数，可单测）

```rust
// 当天未提醒 && 是工作日(is_workday 已有) && now_min >= to_min(cfg.pm_end) && 今日有打工记录
// → 弹一次；弹后内存标记 done(当天不再弹)；跨天 rollover(maybe_rollover_day) 重置标记
fn should_remind_offwork(today_done, is_workday, now_min, pm_end_min, has_record_today) -> bool
```

- 「今日有打工记录」：查询当天 `act_hourly` 是否有行（毫秒级 SQLite，60s 拍内可忽略）；
  无人出勤的休息日/空记录日不打扰
- 重启后若已过点且未弹过：补弹一次（内存标志重启丢失，重新判定成立即弹——合理）
- 通道与久坐同款双通道；应用内横幅文案「到点了，下班吧牛马 · 今天已赚 ¥xxx」（金额取
  hero 口径当日实时），系统通知纯文案「到点了，下班吧牛马 🐎」
- 配置：`remind_offwork_enabled`（默认 `true`）

## 五、D · 全局快捷键

### 绑定（固定组合，v1 不做自定义录入 UI）

| 快捷键 | 动作 |
|--------|------|
| `Alt+Shift+N` | 显隐主窗切换（隐藏→show+focus；可见→hide，等价托盘双击/Esc） |
| `Alt+Shift+P` | 暂停/恢复监控（等价托盘「暂停监控」点击） |

- 依赖：`tauri-plugin-global-shortcut = "2"`（官方插件，Windows 无额外运行时需求）
- 注册时机：setup 中插件 init 回调内注册；`shortcuts_enabled = false` 时不注册
- 冲突处理：注册失败记 `debug.log`，设置页 hint 静态文案「若与其他软件冲突可关闭此开关」；
  不做动态检测 UI（v1 从简）
- 配置：`shortcuts_enabled`（默认 `true`）；运行时改开关 → `apply_monitor_switches` 同链路
  新增 `apply_shortcuts(app)`：先 `unregister_all` 再按需注册
- 权限：`capabilities/default.json` 追加 `global-shortcut:allow-register` /
  `global-shortcut:allow-unregister-all`（Rust 侧注册走插件 API，前端不直调快捷键命令——
  若实测 Rust setup 注册也需权限，则补登记；权限条目按实测增删）

## 六、设置页归宿（一张新卡）

监控卡下方新增「守护」设置卡（`<section class="card">`，与现有卡同款）：

- [x] 久坐提醒（switch）+ 连续活跃阈值 number 输入（分钟）
- [x] 下班提醒（switch）
- [x] 全局快捷键（switch）+ hint：Alt+Shift+N 显隐主窗 · Alt+Shift+P 暂停/恢复
- 接线：load 回填 / readCfg 采集 / change 即存（照抄 `tray_hover_card` 三处范式）
- 快捷键 hint 与开关变更即时生效（`save_config` 后 Rust 端 `apply_shortcuts`）

## 七、口径与不变量

1. 暂停是「不采集」，删除「清空」——暂停前后数据连续，账单无痕可查（热力图暂停时段自然为空格）
2. 久坐连续活跃口径 = 键鼠 last_input 距今 < 5min 即视为「在工位」；纯挂机不键入不算连续活跃
3. 下班提醒只认 `pm_end` 与工作日表（节假日 API 已有），金额展示与 hero 实时口径同源
4. 新配置字段全部 serde `#[serde(default)]` 兼容旧 config.json
5. 所有新增调度挂 scheduler 既有节拍（60s 拍），不新增线程
