## Task A · 后端：pause.rs 手动暂停

1. 新建 `src-tauri/src/pause.rs`：
   - `MANUAL: AtomicBool` + `REST_UNTIL: Mutex<i64>`
   - `set_manual` / `rest_for` / `is_paused` / `rest_remaining_secs`
   - `now_ms()` 复用现有（activity.rs 或 win.rs 里的实现，别新造）
2. `main.rs`：`mod pause;` + 命令 `pause_monitor`（toggle，返回新状态）——供前端/托盘外无直调，
   托盘与快捷键直接调函数；注册进 handler
3. 三处守卫：
   - `activity.rs:672` WM_INPUT 首行守卫链加 `!crate::pause::is_paused()`
   - `app_usage.rs:568` settle 门控链同上
   - `audio_usage.rs` tick_loop 写库分支同上
4. 暂停瞬间结算：托盘切换处（`set_manual(true)` 前）调 `app_usage::settle_now()`——确认
   settle 可被外部主动调（scheduler 每 10s 调的 `tick_now` 就是入口，直接复用）
5. 托盘：`tray.rs` 菜单加 `pause_item`（id="pause"），事件分支切 `pause::set_manual`；
   `refresh_tray` 里 `set_text` 维护「暂停监控/恢复监控」文案
6. `get_status_cmd` 返回体加 `paused: bool` + `rest_secs: Option<i64>`
7. 测试：Rust 单测 `is_paused` 组合 / `rest_remaining_secs` 边界；`cargo test` 绿

## Task B · 后端：remind.rs 久坐 + 下班

1. 新建 `src-tauri/src/remind.rs`：
   - 状态：`SED_RESET_MS: Mutex<i64>`（连续活跃起算点）、`SED_LAST_REMIND_MS: Mutex<i64>`、
     `OFFWORK_DONE: AtomicBool`（当天已弹）
   - 纯函数 `should_remind(...) -> bool` / `should_remind_offwork(...) -> bool`（设计文档口径）
   - `tick(app)`：60s 拍调用——先下班判定再久坐判定；横幅/通知分发
2. 通知双通道：
   - 依赖：`tauri-plugin-notification = "2"`（Cargo.toml + main.rs `init` + capabilities
     `notification:default`）
   - 主窗可见 → `app.emit("remind-banner", { kind, payload })`，前端自绘横幅
   - 主窗隐藏 → `plugin notification` 发系统 toast
3. 下班提醒数据：`pm_end` 从 `AppState.config` 取；「今日有记录」查 `act_hourly` 当天行数
   （`with_db` 锁外查询，照 insights 范式）
4. scheduler 接线：`scheduler.rs` 60s 节拍分支加 `remind::tick`；`maybe_rollover_day` 处
   重置 `OFFWORK_DONE`（或 remind 内部自判日期变更）
5. 测试：纯函数单测全分支（idle 重置/暂停不计时/阈值边界/冷却/补弹/休息日）

## Task C · 后端：全局快捷键

1. 依赖：`tauri-plugin-global-shortcut = "2"`
2. `main.rs` setup：按 `cfg.shortcuts_enabled` 注册 `Alt+Shift+N` / `Alt+Shift+P`；
   handler：N = 显隐切换（`is_visible` 分支 show+focus / hide）；P = `pause::set_manual(!is_paused())`
   + `app_usage::tick_now`（与托盘同款结算）
3. 配置：`config.rs` 加 `shortcuts_enabled: bool`（`#[serde(default = "default_true")]`）；
   `apply_monitor_switches` 旁新增 `apply_shortcuts(app)`（unregister_all → 按需注册），
   `save_config` 命令里接线
4. capabilities：按实测补 `global-shortcut:allow-register` / `allow-unregister-all`
   （Rust 侧注册是否需要权限以 build 报错为准）
5. 测试：注册/解注册冒烟；冲突场景手测（占用 Alt+Shift+N 后启动）

## Task D · 前端：暂停徽章 + 提醒横幅 + 设置卡

1. **暂停徽章**：`renderBadge` 顶部分支——`s.paused`（手动）→「已暂停 · 钱先冻结」；
   `s.rest_secs`（休息中）→「休息中 · X 分钟后恢复」；class `badge off`
2. **提醒横幅**（新 DOM，`index.html` toast 旁）：
   ```html
   <div id="remindBar" class="remind-bar hidden">
     <span id="remindMsg"></span>
     <button id="remindOk" class="ghost">知道了</button>
     <button id="remindRest" class="gold hidden">休息 5 分钟</button>
   </div>
   ```
   - `app.js` 订阅 `remind-banner` 事件：kind=sedentary → 显示 + 两个按钮；kind=offwork →
     显示（带今日已赚金额）只有「知道了」
   - 「知道了」→ invoke 新命令 `remind_ack`（重置起算点）；「休息 5 分钟」→ invoke
     `pause_rest`（rest_for(5min)）
   - 样式：复用 toast 视觉语言（顶部居中、金色描边、可交互），`styles.css` 新增
     `.remind-bar` 块
3. **设置卡「守护」**：monitorCard 下方 `<section class="card">`：
   - `remind_sedentary_enabled` switch + `remind_sedentary_minutes` number(30-120)
   - `remind_offwork_enabled` switch
   - `shortcuts_enabled` switch + hint 文案（Alt+Shift+N / Alt+Shift+P）
   - 三处接线照抄 `tray_hover_card` 范式（load 回填带 `!== false` 缺省 true）
4. 新命令注册 + capabilities：`allow-pause-monitor` / `allow-pause-rest` / `allow-remind-ack`
5. 测试：`scripts/test_guard.js`（暂停）+ `test_remind.js`（横幅/配置）+ `test_shortcut.js`
   （快捷键），每文件 15-30 条断言，含 $() 兜底

## 风险与回退

| 风险 | 缓解 |
|------|------|
| notification 插件 Windows toast 受阻 | 降级：隐藏时改 emit 徽章常驻提示（开窗可见）；插件隔离在 remind.rs 一个函数内 |
| global-shortcut 与他软件冲突 | 注册失败仅记日志 + 设置 hint，不影响主流程 |
| settle 外部主动调的副作用 | 复用 scheduler 同款入口 tick_now，幂等；Task A 单独验证暂停前后账单连续 |
| 60s 拍横幅延迟 1 分钟内 | 口径即分钟级，可接受；文档不承诺秒级 |
