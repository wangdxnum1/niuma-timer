# v1.2.0 数据洞察深化：时段热力图 / 多周趋势 / 身体账单 + 远程排除开关

- 日期：2026-09-18
- 状态：方向已与用户确认（主题=数据洞察深化；功能=时段热力图+多周趋势线+身体账单；
  搭车快赢=远程排除开关；UI=方案 A 并入周账单页 4-tab）
- 依据：库里已积累按小时粒度的键鼠/应用/媒体数据与历史周账单，但只能看「单周汇总」
  和「单日明细」，缺跨时段、跨周的洞察视角

## 目标

1. 把 `act_hourly` / `app_usage_hourly` / `audio_usage_hourly` 的小时级数据变成三张洞察视图
2. 三视图并入周账单页：4-tab 结构 [ 本周账单 | 时段热力 | 趋势 | 身体账单 ]，
   共用现有周导航（`weekOffset` 翻周）
3. 口径全部集中在 Rust 一处聚合（新模块 `insights.rs`，仿 `weekbill.rs` 模式），
   前端只渲染；纯函数 + in-memory 单测
4. 搭车快赢：设置页补 `overtime_exclude_remote` 的开关 UI（后端字段已存在，只差接线）

## UI 归宿：周账单页 4-tab

- 周导航下方加一条分段控件（复用 `.mon-seg` / `.mon-seg-item` 类，
  `data-btab` 属性区分，不与监控分段 `data-mon` 冲突——现有全局监听有
  `if (!btn.dataset.mon) return;` 守卫，天然兼容）
- 四个 tab：**本周账单**（现有 billEmpty/billReceipt/billDash 原样保留，
  小票/仪表盘风格切换逻辑不动）、**时段热力**、**趋势**、**身体账单**
- 「导出 CSV」按钮只在本周账单 tab 显示（导出的是周账单 CSV）
- 周导航对四个 tab 统一生效：
  - 热力图 / 身体账单 = 该周区间聚合
  - 趋势 = 以该周为最新点的最近 8 周窗口
- 懒加载契约：切 tab / 翻周时才 invoke 对应命令（周级聚合，不接 tick 轮询，
  延续 viewBill 既有契约）；每次切换都重拉（本地 SQLite 毫秒级，不做缓存层）

## 三视图设计

### 1. 时段热力图（7 天 × 24 小时）

- 布局：行 = 周一~周日，列 = 0–23 时；纯 div grid（168 格），无外部库
  （应用离线可用，禁用 Chart.js/CDN 依赖）
- 格值 `events` = 该小时键鼠总事件，口径与周账单 `act_events` 一致：
  `moves + left + dbl + right + wheel + mid + xbtn + keys`
- 强度分级：前端对周内最大值做 `sqrt` 归一映射到 4 级金色色阶（品牌金 `#ffd650`
  系）+ 0 级空格；不用分位数（单测更好断言，视觉足够）
- 悬浮提示（title + 自绘 tooltip 二选一，取简单方案 title）：该小时
  `键鼠 N 次 · 前台 X.Xh · 在响 X.Xh`；应用/媒体监控关闭时对应项为 0 不展示
- 汇总行：`本周最拼 14 点时段 · 最拼日 周三`（按小时跨天聚合取最大；
  无数据不显示）
- 空态：整周无键鼠数据 → 一句话空态，不画空网格

### 2. 多周趋势线（最近 8 周）

- 窗口：`[weekOffset, weekOffset+7]` 共 8 周，旧→新排列
- 双序列（口径必须与周账单页一致——复用 `weekbill::week_bill()` 循环聚合，
  绝不另写一份工资口径）：
  - 周入账 `total_income`：金色实线（主视觉）
  - 周摸鱼率 `slack_rate` = Σslack_seconds ÷ front_seconds：红色细线（次视觉）
- 渲染：手写内联 SVG 折线（viewBox 自适应容器宽），数据点圆点 + hover tooltip
  （周标签 · 入账 ¥N · 摸鱼率 N%）；无外部库
- 空周处理：无记录周 income=0 照画（与账单口径一致）；front_seconds=0 →
  slack_rate=null 断线不画
- 边界：翻周到最早可用数据之前，窗口自然落在无数据周，8 个点全 0 → 空态一句话

### 3. 身体账单（本周键鼠损耗）

- 数据源：`act_hourly` 周区间聚合，指标五项（口径全部沿用既有定义，不新造）：
  - 点击 `clicks` = `left − 2×dbl + right + mid + xbtn`… 采用周账单口径
    `left − dbl + right + mid + xbtn`（双击折算 1 次）
  - 按键 `keys` = `SUM(keys)`
  - 鼠标移动 `moves` = `SUM(moves)`
  - 滑动距离 `pixels` = `SUM(pixels)`，前端按 96dpi 换算米（1px = 2.54/96 cm），
    标注「按 96dpi 估算」
  - 滚轮 `wheel_ticks` = `SUM(wheel_ticks)`
- 布局：四张指标卡（点击 / 按键 / 滑行距离 / 滚轮）+ 日均脚注 + 7 日键鼠
  事件金条分布（复用小票 7 日条形视觉思路）+ 最累日一行
  （`最累 周三 · 键鼠 12.3 万次`）
- 文案克制：不搞「≈敲门 N 下」式浮夸换算梗，纯数据 + 日均 + 最累日
- 空态：整周无键鼠数据 → 一句话空态

## 数据与 IPC

新增 **3 个** 命令（`main.rs` 注册在 `get_week_bill,` 之后），聚合逻辑放新文件
`src-tauri/src/insights.rs`（`mod` 注册 + `with_db` 收口 + 锁内取快照锁外查询
的既有纪律）：

```
get_hour_heatmap(week_offset) -> HourHeatmap
get_week_trend(week_offset) -> WeekTrend        // 固定 8 周
get_body_bill(week_offset) -> BodyBill

HourHeatmap {
  week_start, week_end: String,
  cells: Vec<HourCell>,                // 只含有数据的小时格
  peak_hour: Option<u8>,               // 跨天按小时聚合 events 最大者
}
HourCell { date: String, hour: i64, events: i64, front_secs: i64, audio_secs: i64 }

WeekTrend { points: Vec<TrendPoint> }  // 旧→新，8 个
TrendPoint { week_start: String, income: f64, slack_rate: Option<f64> }

BodyBill {
  week_start, week_end: String,
  clicks, keys, moves, pixels, wheel_ticks: i64,
  days: Vec<BodyDay>,                  // 7 天（无记录天 events=0）
  busiest: Option<BodyDay>,            // events 最大的天
}
BodyDay { date: String, weekday: String, events: i64 }
```

- 热力图/身体账单只需 `week_offset`（内部 `Local::now()` 对齐周一，
  与 weekbill 同一 `week_start_of`）；趋势需 `cfg + cur_hol` 快照
  （weekbill 依赖工资与节假日口径），命令层锁内取快照、锁外循环调用
- 前端只传偏移，日期口径不出 Rust（延续 weekbill 决定）

### SQL 口径

- 热力图：`act_hourly` 按 (date,hour) GROUP BY，events 同 act_events 口径；
  `app_usage_hourly` / `audio_usage_hourly` 各按 (date,hour) SUM(seconds)，
  三结果在 Rust 侧按 (date,hour) 合并
- 趋势：循环 `weekbill::week_bill(cfg, hol, week_offset + i)`（i=0..7），
  取 `total_income`；`slack_rate` 由 WeekBill 的 days 求和 slack_seconds ÷
  front_seconds（front=0 → None）
- 身体账单：`act_hourly` 周区间两条 SQL——按天聚合（days/busiest）+
  全区间指标求和（clicks/keys/moves/pixels/wheel_ticks，clicks 口径同上）

## 设置项：远程排除开关（搭车快赢）

- `Config.overtime_exclude_remote`（`config.rs` 已有，serde 默认 true）——
  纯前端接线，不动后端
- 位置：设置页加班配置卡，`「远程会话不计加班」` 开关（复用现有 switch 样式）+
  副文案「检测到远程桌面会话时暂停自动加班记录」
- 机制：loadConfig 时置 checked；change → `saveIfChanged()` 自动保存
  （与其他设置项同路径）；实际排除逻辑在 overtime 检测处已实现

## 边界与空状态

| 情况 | 处理 |
|---|---|
| 热力图整周无键鼠数据 | 空态一句话，不画网格 |
| 趋势窗口含无记录周 | income=0 照画；slack_rate=null 断线 |
| 趋势 8 周全空 | 空态一句话 |
| 身体账单整周无键鼠数据 | 空态一句话 |
| 应用/媒体监控关闭 | 热力 tooltip 对应项不展示（值 0） |
| 键鼠监控关闭（act 数据为 0） | 热力图/身体账单空态；趋势不受影响 |
| IPC/SQL 失败 | 前端 catch 轻提示（沿用「账单加载失败」模式），不白屏 |
| 翻周 | 四 tab 联动各自重拉，未来周封顶沿用 shiftWeek 既有逻辑 |
