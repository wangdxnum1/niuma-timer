# 五项体验问题：修复说明与验证记录

日期：2026-10-06。应用版本保持 1.10.0，本轮未提交、未推送、未发版。

## 1. 切换周期时导出旧数据

**问题说明**：从月报切到年报，在新请求完成前点击存图，会把旧月报金额导出成「年报」。账单 CSV/图片有同类风险。报告第二次读取休假记录时，顶部日期可能先变、正文仍旧。

**原因**：请求开始后旧缓存仍可用，图片模型却读取当前全局跨度；报告日期在休假查询之前就更新了。

**修复方案**：账单与报告数据分别绑定 `span:offset` 周期标识。加载期间隐藏旧正文、显示加载状态、禁用导出；失败清空可导出数据并提供重新加载按钮。报告等待账单和休假两个查询成功后一起更新导航、正文与导出数据。图片操作结束时按当前就绪状态恢复按钮。

**自动验证**：`node scripts/test_experience_fixes.js stale`。先在旧实现观察到「loading report must disable export」失败，修复后通过。用延迟 IPC 执行真实加载/导出函数，检查：

- 月→年加载期间，旧正文隐藏，导出按钮禁用，程序调用导出也被拒绝。
- 年账单已返回但休假未返回时，正文和日期不提前更新。
- 成功后输出年度金额 90000，模型跨度为 year。
- 失败后不能导出旧数据，显示重试，重试成功恢复导出。
- 本期账单图片与 CSV 同样拒绝旧周期数据。

**人工验收**：连续切换周/月/年并翻期，加载中不应出现可点击的旧内容导出；加载完成后核对页面日期、标题、金额与导出文件一致。重新加载按钮应在读取失败时出现。

## 2. 没有记录被显示为零摸鱼并收到评价

**问题说明**：空周期显示完整战绩卡及摸鱼率 0.0%；无前台记录时导出图仍可能出现「天选牛马」评价。

**原因**：渲染/图片模型把缺少证据当成 0；导出评价没有使用界面已有的前台记录门槛。

**修复方案**：无任何证据显示空态并禁用报告导出；只存在加班或休假时保留报告。无前台证据显示「暂无记录」，图片模型保留 null 摸鱼率、未知摸鱼成本，不输出摸鱼评价。有前台证据的真实 0% 仍正常显示。

**自动验证**：`node scripts/test_experience_fixes.js empty`。旧实现先因「no evidence must produce an empty report」失败，修复后通过。覆盖完全空周期、仅加班、仅休假和真实零摸鱼四类输入；验证真实报告 DOM、导出模型及评价门槛。chart 场景另验证 null 摸鱼率能正常绘制图片。

**人工验收**：查看尚无记录的旧月份；再查看只有手工加班或休假标记的月份。前者显示空态，后者保留有效信息；无前台记录时页面和分享图都不出现 0% 或摸鱼评价。

## 3. 时间线页的全局周期导航无效

**问题说明**：时间线页「上一期」改变全局期偏移，却继续查询今天；周/月/年控件与自己的日导航互不联动。

**原因**：周期页使用 weekOffset，时间线使用独立 timelineOffset，但全局控件没有按页面适用范围隐藏。

**修复方案**：给周期控件加容器，在时间线页隐藏，只保留逐日导航；shiftWeek 也拒绝时间线页的程序调用。返回周期页恢复控件，保留原跨度和偏移。

**自动验证**：`node scripts/test_experience_fixes.js navigation`。旧实现先因「timeline must hide unrelated period controls」失败，修复后通过。验证进入时间线、调用全局导航、逐日翻页、返回年报和再翻期的完整顺序；核对最终 IPC 为 get_day_timeline offset=1，以及 get_bill span=year/offset=3。

**人工验收**：年报翻到历史年份，进入时间线并往前翻一天，再回到年报。时间线只显示日导航；年报仍是原年份，周期导航恢复。

## 4. 暂停状态文案互相冲突

**问题说明**：暂停时徽章说「钱先冻结」，动态副标题却说「钱一直在涨」。实际工资计算也没有暂停扣除路径。

**原因**：徽章识别 paused，动态副标题没有该分支；旧文案把监控暂停误写成工资冻结。

**修复方案**：主页和悬停卡明确显示「监控已暂停」；动态副标题优先处理暂停，说明工资仍按作息推算；系统 tooltip 加同样的范围说明。同步双语 README 和代码注释，不改变任何计薪规则。

**自动验证**：`node scripts/test_experience_fixes.js pause`。旧实现先因「paused badge must identify the paused scope」失败，修复后通过。覆盖工作日暂停、休假暂停、休息日暂停，并执行独立悬停卡的真实 render 函数。现有 test_guard、test_tagline、test_hover_card 均随完整套件通过；Rust 侧通过格式/Clippy/测试与编译。

**人工验收**：用托盘菜单或 Alt+Shift+P 暂停，核对首页徽章、副标题、悬停卡及系统 tooltip；暂停期间监控不累计，工资仍按现有作息规则推算。恢复后文案复原，不补记暂停期间监控时长。

## 5. 年报图片柱条挤在一起且标题错误

**问题说明**：12 个年报月桶的相邻柱间隔为零，图表只用到 x=555，而横轴到 x=695；标题仍为「每日进账」。

**原因**：柱条 x 步距扣除了 gap，却没把间隔加回；图表标题写死。

**修复方案**：把绘图区划成等宽槽位，柱条在槽内居中并预留间隔；年跨度标题改为「每月进账」，周/月保留「每日进账」。

**自动验证**：`node scripts/test_experience_fixes.js chart`。旧实现先因「chart must occupy the available width」失败，修复后通过。执行真实 drawReport 并记录 canvas 参数，检查 7/12/28/31 桶的柱数量、有限坐标、正宽度、可见间隔、绘图区边界及标题；同时验证未知摸鱼率绘制不抛异常、不出现评价。

**人工验收**：分别导出周报、28/31 天月份和年报。柱条应分隔、铺满可用图表空间、与标签对应；年报标题为每月进账。用真实字体检查长金额和长文本是否溢出。
