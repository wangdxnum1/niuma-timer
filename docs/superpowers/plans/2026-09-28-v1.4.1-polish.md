# v1.4.1 收尾小版本实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 清掉 v1.4.0 验收遗留项并加固发布链：微信马甲进程图标改借主程序图标、去掉图标多余边框、发布脚本补发布后验证、账单日期范围补年份、旧注释清理，最后补 CHANGELOG 待发布。

**Architecture:** 五处代码改动各自独立、互不依赖：Rust 侧图标捐赠者机制（纯文件系统检索，零新 Win32 原语）与 CSS 样式修正解决用户反馈的两个图标问题；Python 发布脚本在 PATCH 公开成功后追加 `GET /releases/tags/{tag}` 断言；前端一个 `fmtDateRange` helper 替换三处 `slice(5)` 调用；Rust 注释两处措辞更新。每项独立提交，发布与真机验收是用户手工环节。

**Tech Stack:** Tauri 2（Rust 后端 + 原生 JS/HTML 前端）、Python 3 标准库（发布脚本 + unittest）、GitHub Releases API。

**Spec:** `docs/superpowers/specs/2026-09-28-v1.4.1-polish-design.md`（已获用户批准）

## Global Constraints

- **ABBA 死锁纪律**：`ensure_icon` / `cached_icon` 禁止在 `with_db` 回调里调用（ICON_CACHE ↔ DB 锁序），本计划不触碰锁序，两函数的锁序警告注释原样保留。
- **零新依赖**：Rust 不加 tempfile（测试用 `std::env::temp_dir()` 手搓）；Python 只用标准库。
- **零告警门**：每项 Rust 改动后 `cargo check --all-targets` 仍 0 warning；收尾 `cargo build` / `cargo test` 0 warning（v1.4.0 口径，不新增 clippy 门禁）。
- **版本号**：由 `release.bat 1.4.1 /y` 自动同步到 Cargo.toml + tauri.conf.json，本计划不手动改版本号文件。
- **非目标**（spec §3）：不引入 Toolhelp32 进程枚举、不内嵌官方微信图标 PNG、不清扫孤儿图标缓存、不做 Authenticode 签名、不加任何新功能面。
- **提交风格**：conventional commits + 中文描述（如 `fix(monitor): ...`），每任务一个提交。
- **TRAE 沙箱噪音**：python 测试退出码可能因 `__pycache__` / debug.log 被拦为 1，以输出里 `Ran N tests ... OK` 为准。
- **cargo 告警缓存陷阱**：增量编译不重放 warning；验证 0 warning 前先 `cargo clean -p niuma-timer` 强制重编。

```rust
/// 图标捐赠者：显示名已归一、但 exe 自身图标不代表主程序的「马甲进程」。
/// 从马甲进程完整路径向上层目录找主程序 exe 借图标（同安装树内检索）。
const ICON_DONORS: &[(&str, &[&str])] =
    &[("wechatappex.exe", &["weixin.exe", "wechat.exe"])];

/// 马甲进程 → 捐赠者主程序 exe 路径。非马甲或树内未命中返回 None，
/// 调用方回退自身图标（= 旧行为，无回归）。检索自浅而深：目录层
/// 优先于捐赠者顺序，同层按表内顺序；Windows 文件系统大小写不敏感，
/// 小写文件名 join 后 `exists()` 即可命中 `Weixin.exe`。
fn donor_exe_path(exe_path: &str) -> Option<String> {
    let path = std::path::Path::new(exe_path);
    let name = path.file_name()?.to_string_lossy().to_lowercase();
    let donors = *ICON_DONORS.iter().find(|(k, _)| *k == name)?.1;
    let mut dir = path.parent()?.to_path_buf();
    for _ in 0..3 {
        for donor in donors {
            let cand = dir.join(donor);
            if cand.exists() {
                return Some(cand.to_string_lossy().into_owned());
            }
        }
        dir = dir.parent()?.to_path_buf();
    }
    None
}
```
