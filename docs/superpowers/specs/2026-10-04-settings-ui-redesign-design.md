# 设置页布局与逐项内容设计

状态：用户已确认逐项交互原型，并于 2026-10-04 明确要求编写 spec、plan 后直接实施。

## 目标与边界

在现有 520×700 Windows 窗口内，让用户容易找到设置、理解实际生效规则、看到修改结果。设计依据是本会话确认的 `settings-detail-preview.html`，实现使用真实配置与状态，禁止硬编码原型中的日期、工作日数、版本或金额。

保留 Tauri 2、原生 JS、现有配置字段、六组设置、自动保存、加载失败门闸、备份保护与还原重启流程。不新增依赖、数据库表或业务命令，不更改薪资、加班、提醒的后台计算规则，不发布版本。保留当前未提交的构建指纹改动。

## 页面与控件

- 深色灰阶与金色选中态，原侧栏保留。六组：薪资与作息、加班、守护、数据监控、外观、系统与数据。
- 页头显示自动保存状态及规则；两行三列分类导航常驻可见，点击滚动定位，不隐藏其他分类。滚动同步当前分类，回到设置页保留滚动位置；支持键盘与减弱动态效果。
- 表单双列时标签在上、控件在下。长下拉框独占一行。设置页输入高度 35px、圆角 7px、卡片圆角 12px；输入值和下拉选项使用 14px、500 字重，单位 12px，提高输入内容和占位文字对比度；样式限于设置页，其他页面保持原有样式。
- 数字旁显示单位，输入框可缩放；说明紧贴所属设置，长说明使用具体标题折叠。有效功能的参数按开关收起或禁用，但不清空已填值。所有显隐使用 `.hidden` 类。
- 320px 内容和常见 Windows 缩放下不得横向溢出。保留焦点轮廓、label 关联；分段和预览卡的选中状态写入 ARIA。

## 薪资与作息

- 计薪方式为月薪/时薪分段；金额用元/月或元/小时。发薪日移出仅月薪区域，两种模式都可设置。
- 工作日选择自动/手动：自动保留 `workdays_override=null`；手动输入 1–31 天，沿用 `workdays_override_for` 当前年月。切自动清除覆盖，切手动从有效覆盖或已知工作日数填入，数据尚未到达时不猜测。
- 已过期的工作日覆盖显示为自动，不把旧月份数值重新保存成本月覆盖。当前年月、工作日数由运行时和后端结果提供。
- 上午和下午各显示开始/结束；两段结束不得早于开始，下午开始不得早于上午结束，全天工时须大于 0。同一段起止相等允许表示不工作。
- 展示全天计薪时长、参考时薪及每日满勤金额；月薪参考费率使用真实本月工作日数。未获取工作日数或表单不合法时显示待完善/待获取，不显示伪造金额。
- 工作日数据优先复用后端当前状态；需要时扩展 `DayStatus.monthly_workdays` 并验证序列化，不从前端猜节假日。手动刷新有忙碌状态和失败反馈。

## 加班与守护

- 名称：自动记录加班、远程操作时不自动记录、工作日加班费、加班餐补。说明锁屏离开的自动记录规则、远程排除不影响手动补录。
- 加班关闭时子参数禁用，餐补关闭收起金额，休息日开关控制子参数。可选起算时间保留空值跟随下班的语义，并显示当前跟随时间；休息日起算空值默认 09:00。
- 休息日/节假日费率为空时显示实际沿用金额；0 是明确的零费率，不得当成空值。
- 久坐输入标签为连续使用电脑，单位为分钟后提醒，提供 30/50/60 分钟快捷值，范围仍为 1–120。说明锁屏/闲置 5 分钟重新计时。
- 下班提醒说明关联下午下班时间，发薪日提醒说明发送上月战绩。月份不足发薪日的现有提醒行为不得承诺自动顺延。
- 专注阈值命名最短专注时长，范围 10–120 分钟；说明工作类前台且持续活跃的条件。快捷键用键帽展示操作对应关系。

## 数据监控与外观

- 三个监控开关分别说明键鼠活动统计、前台应用使用时长、媒体播放时长；关闭保留历史。
- 白名单命名仅记录指定应用。应用监控关闭时禁用名单开关与编辑区，不删除名单。空名单开启时直接提示当前仍记录全部应用；非空名单显示条目数，匹配使用展示名，大小写不敏感，保留去重和回车添加。
- 时长选项缩短为时、分、秒 / 时、分 / 小数小时，旁边显示一致的示例。
- 首页副标题就地预览，动态模式复用 `dynamicTagline(lastStatus)`，未取到状态时显示等待；自定义空值使用现有动态回退，字符计数 0–40。
- 保留小票/仪表盘双预览卡，文案改为汇总明细/对比趋势，并支持键盘选中；托盘开关说明关闭使用系统文字提示。

## 系统与数据

- 保留期永久时说明保留全部历史；有限期直接说明整理会清理超过期限记录，建议先备份。整理仍按既有后台规则执行，不声称整理完全不删除数据。
- 保留真实存储占用、忙碌状态和释放空间反馈。备份日期、大小、版本层次分明，目录可折行，残缺备份可删不可还原。
- 删除确认说明仅删除备份文件且无法恢复；还原确认明确当前数据与设置会替换、先保护性备份、完成后重启。复用现有确认组件，不新增虚假成功状态。
- 开机启动说明登录 Windows 后在托盘运行；实际状态继续读注册表。更新频率说明贴近自动检查开关，手动检查入口仍进入更新页。

## 校验与保存

- 编辑无效数字/时间时在字段附近显示错误，标记 `aria-invalid`；不静默钳成另一个值。金额非负、发薪日 1–31、工作日数 1–31、久坐 1–120、专注 10–120。
- 核心金额或发薪日留空仍保持原有省略字段、后端保留旧值的语义。可选费率留空仍发送 null。原配置中保留期的非预置数值应可回显而不自动变为永久。
- 只校验启用且可编辑的字段；禁用/隐藏字段保留原值。表单不合法时阻止整份配置写入，明确提示待修正。
- 加载失败禁止保存；保存中/成功/失败状态均来自实际调用。串行保存配置快照，快速连续编辑不能让旧响应覆盖新快照；失败保留重试机会，成功状态不得覆盖尚未保存的输入。
- 首次加载完成后顶部状态为空；顶部保存成功状态显示 2 秒后淡出，保持标题布局稳定；新的编辑、保存中或失败状态取消旧计时器并立即可见。保存中和失败提示不自动隐藏，减少动态效果时不播放淡出动画。
- 低频 UI 更新从 load、input、change、状态 tick 驱动，不新增轮询或网络请求。UI 辅助集中在 `settings_ui.js`，配置持久化仍在 `settings.js`。
