- Windows crate API 查询经验（0.61.3，registry 在 ~/.cargo/registry/src/rsproxy.cn-*/windows-0.61.3）：
  - `GetLastInputInfo(plii: *mut LASTINPUTINFO) -> BOOL`，`LASTINPUTINFO { cbSize: u32, dwTime: u32 }`（repr(C) + Default），均在 `Win32::UI::Input::KeyboardAndMouse`；`GetTickCount() -> u32` 在 `Win32::System::SystemInformation`。
  - `BOOL` 定义在 windows-result crate：`pub struct BOOL(pub i32)`，有 `as_bool()` / `ok()`（**不是** `is_err()`，后者是 HRESULT 的写法）。
  - `&mut T → *mut T` 是标准 coercion，函数参数位置自动应用，不必手写 `as *mut _`。
  - 加 Win32 feature 前先查 Cargo.toml 已启用列表，避免漏加导致编译失败。
